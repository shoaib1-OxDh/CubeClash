# Cube Clash

An original Android arcade game that combines 2048-style number merging with snake-style movement in an open 3D
arena. You start as a single cube showing **1**, collect numbered cubes, merge equal neighbours
(1+1=2, 2+2=4, …) and outgrow AI rival chains — completely offline.

Native Android: **Kotlin + OpenGL ES 3.0**, built with Gradle. No game engine, no licences and no third-party
assets — cube textures, effects, sounds and music are generated by the game's own code.

## Get the APK

Every push runs **Actions → Build APK**. Open the latest run and download **CubeClash-apk-N** from *Artifacts*.
It contains:

* `CubeClash-1.0.N.apk` — optimised release build (signed with the debug key unless release signing is set up);
  install this one on your phone.
* `CubeClash-1.0.N-debug.apk` — debug build.

On the phone: open the APK and allow installing from that source. New builds install over old ones.

## Gameplay

* **Move** with the floating joystick (touch the lower-left of the screen) or *Tap to steer*. The chain always
  moves; you steer.
* **Collect** cubes whose number is ≤ your leading cube; bigger ones are greyed out until you grow.
* **Merge**: equal neighbours merge into double, one step at a time
  (`[8,4,2,1] + 1 → [8,4,2,2] → [8,4,4] → [8,8] → [16]`).
* **Boost** (lower-right) drains the energy ring; it refills when released.
* **Fight**: your leading cube is your strength. Hit a weaker rival's head to defeat it or its body to cut its tail;
  hit a stronger rival and you're out; equal strength bounces. Defeated chains burst into cubes.
* **Modes**: Classic Arena, Endless Growth (you can't be defeated), Survival Challenge (rivals ramp up every minute).
  **Rivals**: Easy / Normal / Hard.

Exact, configurable rules: [`docs/GAME_RULES.md`](docs/GAME_RULES.md).

## Project structure

```
engine/   Pure Kotlin/JVM game simulation (no Android): numbers & merging (MergeSystem), chain model, path trail,
          spatial hash, weighted spawning, combat rules, AI, boost, modes, save data, and World — the complete
          arena simulation stepped once per frame. Unit tests in engine/src/test.
app/      Android app (framework only, no AndroidX):
  MainActivity        menu ↔ arena, lifecycle, back button, keyboard
  GameSession         one run: World + input brain + flags
  gfx/GameRenderer    GLSurfaceView renderer: instanced rounded cubes with a number atlas, procedural grid ground
                      and boundary, blob shadows, team rings, glow halos, particles, follow camera
  gfx/FacePainter     draws numbered cube faces (atlas + UI icons); Palette = per-skin colours
  ui/HudView          Canvas HUD + multi-touch controls (joystick, boost, pause, tap-to-steer), minimap, labels
  ui/MenuScreen, ui/GameScreen, ui/Dialogs   menus, settings, pause, game over, stats, customize, credits
  Sound               synthesised SFX/music (SoundPool / MediaPlayer)
  SaveStore, Settings JSON progress with backup + sanitising; SharedPreferences settings
.github/workflows/
  build-apk.yml             tests + debug & release APKs on every push (no secrets needed)
  emulator-screenshots.yml  runs the APK on an emulator and captures screenshots (branch `emulator-screens`)
```

Threading: the `World` is stepped on the GL thread inside `onDrawFrame`; the UI thread only writes the input
brain's volatile fields, and reads a lock-protected `HudState` snapshot that the renderer fills each frame.

## Build locally

Requires JDK 17 and the Android SDK (Android Studio works out of the box).

```bash
./gradlew :engine:test
```

```bash
./gradlew :app:assembleDebug
```

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Debug / CI helper: `adb shell am start -n com.oxdh.cubeclash/.MainActivity --ez autoplay true --ei mode 0`
starts a match where the AI plays for you.

### Release signing (optional, for Google Play)

Create an upload keystore once and keep it safe:

```bash
keytool -genkeypair -v -keystore cubeclash-release.jks -alias cubeclash -keyalg RSA -keysize 2048 -validity 10000
```

Locally, create `keystore.properties` (git-ignored) with `storeFile`, `storePassword`, `keyAlias`, `keyPassword`.
On GitHub add the secrets `KEYSTORE_BASE64` (`base64 -w0 cubeclash-release.jks`), `KEYSTORE_PASSWORD`,
`KEY_ALIAS`, `KEY_PASSWORD`; the release APK is then signed with your key.

## Configuration

All balance lives in `engine/src/main/kotlin/com/oxdh/cubeclash/engine/Config.kt` and `Numbers.kt`
(`GameConfig`, `RulesConfig`, `MovementConfig`, `BoostConfig`, `SpawnConfig`, `ArenaConfig`, AI presets,
`GameModeSettings`). In-game settings: volumes, mute, joystick / tap steering, turn speed, joystick size, camera mode,
zoom, follow speed, minimap, low effects, 30/60 FPS, reset progress.

## Technical notes

* Min Android 7.0 (API 24), target API 35, OpenGL ES 3.0, no permissions, works offline.
* Portrait and landscape, notches and gesture bars handled (safe insets).
* Performance: one instanced draw call for all cubes, one per sprite layer; spatial hashes for queries;
  change-only label strings; idle animation only near the camera; low-effects mode and 30 FPS option.
